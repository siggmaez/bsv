# BSV — Brawl Stars Visuals

Самостоятельный Android-прототип визуального меню, версия 0.1.0. Kotlin, Jetpack Compose, Android 8.0+ (API 26), горизонтальная ориентация. Не использует APK или ресурсы игры, сеть, аккаунты, античит или игровые данные. Все эффекты — демонстрации внутри приложения.

## Возможности

- Home: статус локальных модулей, число активных настроек, сведения об устройстве, сброс с подтверждением.
- Profile: шесть собственных эмблем рангов, локальный предпросмотр кубков и независимый сброс. Оформление профиля обозначено как будущая функция.
- Visuals: семь включаемых демонстраций на Canvas с индивидуальной интенсивностью.
- Interface: три темы, четыре акцентных цвета, масштаб, прозрачность, скорость и отключение анимаций. Размытие декоративного фона поддерживается Android 12+; на Android 8–11 фон остаётся без размытия.
- Settings: English / Русский, автосохранение DataStore, ручное сохранение, сброс, JSON-импорт/экспорт через системный выбор файла, отладочная информация.
- Кнопка BSV открывает/закрывает меню, перемещается пальцем; размер, прозрачность и относительные координаты сохраняются.

## Сборка

Требуются JDK 21, Android SDK Platform 35 и Build Tools 35.0.0. Bytecode target — Java 17. Gradle Wrapper 8.11.1 и Android Gradle Plugin 8.9.2 закреплены в проекте.

1. Откройте проект в Android Studio и задайте SDK в `local.properties`: `sdk.dir=C:/Android/sdk` (ваш путь).
2. Windows: `./gradlew.bat :app:assembleDebug :core-settings:testDebugUnitTest :app:lintDebug`.
3. Linux/macOS: `chmod +x gradlew`, затем `./gradlew :app:assembleDebug :core-settings:testDebugUnitTest :app:lintDebug`.
4. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Собственного C/C++ и NDK-кода нет. Зависимости AndroidX включают libandroidx.graphics.path.so и libdatastore_shared_counter.so. APK универсальный, совместим в том числе с ARM64, ARMv7, x86 и x86_64 при наличии соответствующей Android runtime. ABI-фильтров нет. Название `BSV-v0.1.0-android-universal-debug.apk` честно отражает содержимое; суффикс arm64 был бы вводящим в заблуждение.

## GitHub Actions и установка

В [Actions](https://github.com/siggmaez/bsv/actions) откройте успешный запуск Android Debug APK. Скачайте artifact `BSV-v0.1.0-android-universal-debug`, распакуйте ZIP и установите APK на Android 8.0+. Разрешите установку из выбранного файлового менеджера, если Android запросит это. Через ADB: `adb install -r BSV-v0.1.0-android-universal-debug.apk`.

Workflow ставит JDK/SDK, собирает APK, запускает unit-тесты и lint, проверяет наличие файла и загружает artifact. Сборка debug подписана отладочным ключом; для выпуска нужен отдельный защищённый signing-процесс.

## Архитектура

`app` — Activity, навигация, ViewModel и системные документы. `core-ui` — тема и компоненты. `core-settings` — модель, JSON-кодек, нормализация, контракт репозитория, реализация DataStore и независимый `VisualPreviewPort`. Четыре `feature-*` — экраны Home, Profile, Visuals и Interface. Settings размещён в app согласно запрошенному списку модулей.

UI получает неизменяемый Settings и callback обновления; ViewModel последовательно записывает последнее состояние через conflated channel. Чтение выполняется перед разрешением изменений. Ошибки хранилища и файлов выводятся в Settings. Импорт ограничен 64 KiB, числовые диапазоны и имена модулей проверяются. Неизвестные поля JSON допускаются для будущей совместимости. Формат не содержит аккаунтов или секретов.

Модель, кодек и интерфейсы не зависят от игры. Это граница для будущей интеграции; рабочей игровой интеграции нет. Для iOS предстоит выделить чистую модель в KMP-модуль, реализовать хранилище и UI платформы; готовый iOS-порт не заявляется.

## Проверка

Unit-тесты покрывают JSON round-trip, нормализацию опасных диапазонов, неизвестные поля, счётчик настроек, отклонение повреждённых и слишком больших файлов. Результаты локальной сборки отражены в TASKS.md.

Ручная приёмка на устройстве: пройти все вкладки, включить каждый эффект и открыть его настройки; изменить профиль и перезапустить приложение; экспортировать JSON, сбросить и импортировать; проверить языки, масштаб 0.8/1.2, отключение анимаций, прозрачность, перемещение кнопки к четырём углам; быстро переключать вкладки; проверить 640×360 и 960×540 dp, большой системный шрифт, Android 8 и 12+. Фактическую плавность и отсутствие наложений нужно подтвердить на этих устройствах.
