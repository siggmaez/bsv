# Эксперимент встраивания BSV

Локальный адаптер для пользовательской установки клиента 69.414. В репозитории находятся только собственные исходники адаптера. Извлечённые APK, код и ресурсы игры, ключи и производные APK находятся в игнорируемых `.tooling` / `dist` и не публикуются вместе с исходниками.

`BsvProvider` регистрирует Android ActivityLifecycleCallbacks. После открытия игровой Activity он добавляет обычный View в её окно. Отдельное разрешение SYSTEM_ALERT_WINDOW не требуется; других приложений этот View не касается. Пакет копии — `dev.bsv.client`, authorities провайдеров разделены с исходной установкой. Исходные DEX и нативные библиотеки не патчатся. Протокол, серверные данные и проверки клиента не изменяются.

Первая smoke-сборка проверяет только запуск перепакованной игры и открытие кнопкой BSV встроенной информационной панели. Это **не полная интеграция Compose-редактора** и не подключение визуальных модулей к движку игры. Standalone-приложение в других модулях проекта сохранено.

## Результат проверки 17 октября 2026

- Пакет `dev.bsv.client` установлен рядом с исходной игрой в BlueStacks (Android 9, ARM64 через трансляцию).
- Подпись APK проверена apksigner: v2 и v3 valid.
- Исходные DEX, нативные библиотеки и assets проверены по размеру и ZIP CRC: 35 956 записей без отличий. Добавлен отдельный DEX адаптера; изменены только manifest / упаковка / подпись.
- При запуске копия получает нативный `SIGSEGV`, `SEGV_MAPERR`, адрес `0xdead0000`, до сообщения `BSV: In-process menu registered`. Activity не доходит до меню. После обнаружения повторных падений тестовая копия остановлена через force-stop.
- Контрольный запуск исходного пакета в том же экземпляре BlueStacks успешен: Activity отображается, процесс остаётся запущенным.
- Причина нативного завершения пока не установлена. Эти наблюдения не доказывают конкретную проверку подписи, античит или ошибку транслятора. Отключение защитных проверок не выполнялось.

**Рабочий интегрированный клиент не получен.** Диагностический APK не публикуется как готовый релиз. Для полноценной интеграции нужен клиент, доступный для сборки из исходников, либо поддерживаемая точка расширения. Полный Compose-редактор нельзя считать встроенным по одному факту успешной установки перепакованного APK.

## Локальная сборка

Нужны JDK 21, Android SDK 35 / Build Tools 35.0.0, APKEditor 1.4.9, стандартный локальный Android debug keystore и все APK одной пользовательской установки в `.tooling/brawlstars-original`. Выполните `./integration/build-client.ps1`. Подробности инструментов: [APKEditor](https://github.com/REAndroid/APKEditor), [Android apksigner](https://developer.android.com/tools/apksigner).

Скрипт формирует `dist/BSV-client-69.414-smoke-debug.apk`. Он содержит только ARM64-библиотеки, извлечённые из данной установки. Это не универсальный standalone APK из Releases. Совместимость с другим эмулятором и официальными сервисами требует отдельной проверки; факт успешной перепаковки её не подтверждает.
