# Changelog

## Unreleased — эксперимент интеграции

- Добавлены собственный Android ContentProvider / View-адаптер и локальный скрипт упаковки отдельного пакета `dev.bsv.client`.
- Проверены установка, подпись и неизменность исходных кодовых/ресурсных записей. Обнаружен SIGSEGV клиента до инициализации адаптера; рабочая игровая интеграция не заявляется.
- Исходные файлы игры и производные APK не добавлены в git или Releases. Standalone-приложение не изменено.

## 0.1.0 — 2026-10-17

- Создан модульный Android-проект на Kotlin/Compose, API 26+.
- Добавлены пять разделов меню, оригинальный брендинг, темы и локальные демонстрации.
- Добавлены DataStore, MVVM, валидация JSON, импорт/экспорт и русский/английский интерфейс.
- Добавлены плавающая кнопка, анимации и настройки доступности движения.
- Добавлены Gradle Wrapper, unit-тесты и GitHub Actions для универсального Debug APK.
- Игровая интеграция и iOS оставлены для будущих версий.

### Фирменное оформление

- Добавлены оригинальные BSV-логотип и баннер 2560×1440, исходники и промпты.
- Добавлены WebP-ресурсы, adaptive launcher foreground/background и mipmap mdpi–xxxhdpi.
- Добавлены системный SplashScreen и фирменный Compose-индикатор реальной загрузки без искусственной задержки.
- Добавлен брендинг Home и заголовка без замены существующих функций.
- Добавлены UI-проверки загрузочного компонента, пропорций баннера и adaptive icon.
