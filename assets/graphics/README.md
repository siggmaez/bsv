# BSV graphics

Оригинальные ресурсы созданы встроенным ImageGen по цветовой и типографической стилистике предоставленных референсов. Звёзды, черепа, персонажи и логотипы Supercell не использованы. Референсы не включены в APK или репозиторий.

| Файл | Назначение |
| --- | --- |
| bsv-logo-source.png | Неизменённый результат генерации, 1254×1254, RGBA |
| bsv-logo.png | Логотип с обрезанными прозрачными полями, 1208×519, RGBA |
| bsv-banner-source.png | Неизменённый результат генерации, 1672×941 |
| bsv-banner-2560x1440.png | Баннер точного размера 2560×1440; масштабирование с сохранением пропорций |
| bsv-icon-512.png | Превью полной иконки 512×512 |
| bsv-icon-foreground.png | Прозрачный adaptive foreground 432×432, логотип в безопасной зоне |
| bsv-icon-background.xml | Исходный векторный фон адаптивной иконки |

В `core-ui/src/main/res/drawable-nodpi` находятся мобильные WebP: баннер 1280×720 (~91 КБ) и логотип 640×275 с alpha. Image использует ContentScale.Fit; баннер имеет контейнер 16:9, логотип сохраняет собственные пропорции. Полноразмерные источники не попадают в APK.

В `app/src/main/res/mipmap-*` находятся legacy/round иконки 48/72/96/144/192 px и adaptive foreground 108/162/216/324/432 px. `mipmap-anydpi-v26` соединяет foreground и оригинальный векторный background. Поля foreground соблюдают центральную безопасную область; Android применяет маску лаунчера сам.

Для повторного получения размеров и WebP выполните `python scripts/prepare_graphics.py` из корня проекта (нужен Pillow). Скрипт не генерирует новую графику: он детерминированно обрабатывает сохранённые источники. Пользовательские изображения на диске не меняются.
